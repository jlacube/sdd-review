# C001 — Error catalogue

Kinds: **error** stops the operation and changes nothing; **notice** is reported and the
operation continues. Every error and notice is also logged with operation, identifying inputs and
cause (constitution NFR-D-04). Placeholders in angle brackets are filled with the actual values.
CLI exit codes: C001-IF-001 §Exit codes; HTTP responses use `application/problem+json` with the
code in the `code` member (C001-IF-002). A dash in the last column means that the surface has no
operation that can raise the code (the CLI records verdicts only, C001-IF-001).
