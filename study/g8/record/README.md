# study/g8/record: pseudonymised study record

This folder holds the layout and the rules described in `../README.md` (Record layout,
Confidentiality rules). Participants appear here by code only: no names, contacts or signed
consent forms. Check the folder with `npm run study -- g8-check-record --rows <list>`.

It is empty until the assignment draw of C001-T-112 (`npm run study -- g8-assign`).
